# Mini Data Quality Tool

أداة تدريبية صغيرة بلغة Python لتنظيف ملفات CSV المحلية، مع تطبيق Git وGitHub والاختبارات وClean Code. تقرأ البيانات، وتوحد أسماء الأعمدة، وتعالج القيم المفقودة، وتحذف الصفوف المكررة، ثم تحفظ النتيجة وتعرض تقريرًا مختصرًا.

## الإعداد

استخدم Python 3.13، وهو الإصدار المستخدم في GitHub Actions. من مجلد المشروع أنشئ بيئة افتراضية:

```shell
python -m venv .venv
```

فعّلها في Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

أو في Linux وmacOS:

```shell
source .venv/bin/activate
```

ثم ثبّت مكتبة التشغيل وأداة الاختبار:

```shell
python -m pip install "pandas>=3.0,<4" "pytest>=9,<10"
```

## التشغيل

نفّذ الأوامر من مجلد المشروع:

```shell
python main.py data/sample.csv
python main.py "path/to/input.csv"
python main.py --help
```

يجب أن يكون الملف بامتداد `.csv` وترميز UTF-8، مع صف أسماء أعمدة غير فارغة وصف بيانات واحد على الأقل، وأن يتطابق عدد الخلايا مع عدد الأعمدة. استخدم أسماء أعمدة مميزة حتى بعد توحيدها.

## طريقة التنظيف

1. يحوّل `adapter.py` سجلات التحميل إلى `DataFrame`. الخلايا الفارغة أو التي تحتوي مسافات فقط تُعد قيمًا مفقودة. يتحول العمود إلى أرقام إذا كانت جميع قيمه غير الفارغة قابلة للتحويل؛ الأعمدة المختلطة تبقى نصية، والقيم الحرفية مثل `NA` و`NULL` و`nan` تبقى نصوصًا. العمود الفارغ بالكامل يُعامل كنص لعدم توفر معلومات عن نوعه.
2. تُحوّل أسماء الأعمدة إلى أحرف صغيرة، وتُستبدل كل مجموعة لا تتكون من الأحرف الإنجليزية `a-z` أو الأرقام `0-9` بشرطة سفلية، وتُحذف الشرطات من البداية والنهاية. الاسم الذي يصبح فارغًا يُستبدل بـ `unnamed_column`.
3. تُملأ القيم الرقمية المفقودة بالوسيط، والنصية بـ `unknown`. تدعم وحدة التنظيف أيضًا العمود الرقمي المفقود بالكامل وتملؤه بصفر عند استدعائها مباشرة ببيانات ذات نوع رقمي.
4. تُحذف الصفوف المتطابقة بعد المعالجة، مع الاحتفاظ بأول ظهور وترتيب الصفوف.

استنتاج النوع الرقمي قد يزيل التنسيق النصي مثل الأصفار في بداية الأرقام. هذه أداة بسيطة لبيانات صغيرة؛ لا توفر مخطط أنواع مخصصًا للأعمدة.

## المخرجات

تُحفظ البيانات في `output/cleaned.csv` دون عمود فهرس إضافي. يُنشأ مجلد `output/` عند الحاجة، ويُستبدل الملف الناتج عند التشغيل التالي. المسار نسبي لمجلد التشغيل. لا تُرفع الملفات الناتجة إلى Git.

نتيجة تشغيل الملف التجريبي:

```text
Data Cleaning Report
====================

Rows before cleaning: 8
Rows after cleaning: 7
Duplicate rows removed: 1
Missing values handled: 4
```

يمثل عدد القيم المفقودة عدد الخلايا المعالجة قبل حذف التكرارات. يظهر التقرير بعد نجاح الحفظ. عند فشل القراءة أو التحقق أو الحفظ، تظهر رسالة `Error:` على stderr وينتهي البرنامج بالرمز `1`. أخطاء معاملات سطر الأوامر تستخدم الرمز `2`، والنجاح الرمز `0`.

## الاختبارات

```shell
python -m pytest -q
```

تشمل الاختبارات التحميل والتنظيف والتقرير والتصدير، والتشغيل الكامل على الملف التجريبي، ورسائل الأخطاء ورموز الخروج. يشغّل `.github/workflows/tests.yml` المجموعة كاملة عند فتح أو تحديث PR باتجاه `main` وعند الدفع إلى `main`. تظهر النتيجة في فحص `tests` داخل PR.

## هيكل المشروع

```text
main.py                     # معاملات التشغيل وربط المكونات
src/
  loader.py                 # قراءة CSV والتحقق منه
  adapter.py                # تحويل السجلات النصية إلى DataFrame
  cleaner.py                # عمليات التنظيف وإحصاء نتائجها
  report.py                 # إنشاء التقرير النصي
  exporter.py               # حفظ CSV
tests/
  test_loader.py
  test_cleaner.py
  test_report.py
  test_exporter.py
  test_main.py              # اختبارات الربط وسطر الأوامر
data/sample.csv             # بيانات تجريبية صغيرة
output/                     # النتائج المحلية
.github/workflows/tests.yml # الاختبارات الآلية
PROJECT_PLAN.md             # النطاق ومسؤوليات الفريق وطريقة العمل
```

لكل إيشو فرع مستقل وPR للمراجعة. تفاصيل العمل الجماعي ومعايير الإنجاز موجودة في [خطة المشروع](PROJECT_PLAN.md).
